# Sutíne by Yojana: Pop-up Stall · FINAL print files

The two files to print are in `final/`:

| File | Size | Print on | Qty |
|------|------|----------|-----|
| `1-table-runner-80x180cm.pdf` | 80 × 180 cm | Heavy cotton canvas or linen-look fabric, matte, dye-sublimation, hemmed edges | 1 |
| `2-follow-us-QR-card-A5.pdf` | A5 (148 × 210 mm) | 350 gsm matte card | 2 |

**Runner:** lay it front to back across a 6 ft table over a plain base cloth. The olive end goes at the back. The flowers, wordmark and maroon hem hang down the front, facing customers.
**Card:** stand it in a wooden block or clip it to a stand.

QR codes (each decoded from the final PDF, and each link opened):
- Large code → Instagram, instagram.com/sutine_by_yojana
- Small left → TikTok, tiktok.com/@sutine.by.yojana
- Small right → sutine.com (tagged `utm_source=popup`)

Rebuild with `python3 final.py` (it uses the helpers in `build.py`).
