Notes for the printer

  • All files are vector PDFs at 100% finished size, so any size prints sharp. Fabric pieces: add 3 cm hem allowance on every side (no bleed is built in). Cards: print edge to edge, then trim to A5.
  • Colours: cream #F7F3EC · maroon #7A1F26 · olive #5F6B3A · ink #2A2523. Ask for a small fabric test swatch first, because maroon tends to print darker on canvas.
  • On natural or undyed linen, the cream background can be left unprinted so the fabric shows through.
  • Fabric printing usually takes 1–2 working days, so order 01–03 first.
